# Screenshots

Hier können später drei Screenshots der App abgelegt werden:

- `hauptfenster.png` – Hauptfenster mit neutralem, leerem oder synthetischem Beispielinhalt
- `aktions-editor.png` – Aktionsliste und sichtbare Bedienelemente des Editors
- `einstellungen.png` – Einstellungsansicht

Bitte PNG-Dateien mit ungefähr 1200 Pixeln Breite verwenden. Vor dem Ablegen private Inhalte entfernen: keine echten Makronamen, Eingaben, Fenstertitel, Benutzernamen, Pfade oder Benachrichtigungen. Die Bilder werden in der README erst eingebunden, wenn sie vorhanden und geprüft sind.
