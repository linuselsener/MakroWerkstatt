# Sicherheitsmeldungen

Unterstützt wird jeweils die neueste veröffentlichte Version von MakroWerkstatt.

Bitte melde eine vermutete Sicherheitslücke bevorzugt vertraulich über **Security → Advisories → Report a vulnerability** und GitHubs Funktion *Private vulnerability reporting*, sobald sie für dieses Repository verfügbar ist. Eröffne dafür kein öffentliches Issue.

Makros werden lokal gespeichert und standardmäßig mit Windows DPAPI für das aktuelle Windows-Benutzerkonto verschlüsselt. Makros können trotzdem Passwörter oder andere vertrauliche Eingaben enthalten. DPAPI schützt nicht vor Schadsoftware, die im selben Benutzerkonto läuft.
